# Diabetes Prediction Project

## Overview

This project predicts whether a person has diabetes using Machine Learning techniques.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Features

* Data Cleaning
* Data Visualization
* Correlation Analysis
* Logistic Regression Model
* Accuracy Evaluation

## Dataset Features

* Pregnancies
* Glucose
* BloodPressure
* SkinThickness
* Insulin
* BMI
* DiabetesPedigreeFunction
* Age

## Machine Learning Algorithm

Logistic Regression

## Output

The model predicts diabetes diagnosis based on health parameters.

## Conclusion

The project demonstrates how Machine Learning can help in healthcare prediction systems.
